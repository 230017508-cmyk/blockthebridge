# 垂直距离 · Vertical Distance

> 当你要在教学楼内上下楼时，等电梯还是走楼梯更快？

“垂直距离”是一个面向校园场景的智能出行决策网页。用户输入所在楼层与目的楼层后，系统会结合电梯位置、载客量、排队人数、上下客停靠与楼梯体力消耗，实时给出“等电梯”或“走楼梯”的建议及预计时间。

## 如何使用

1. 选择你所在的楼层和要去的楼层。
2. 如携带较重物品，可开启“携带重物”。
3. 选择当前人流状态：平峰、上课前或课间换课。
4. 查看系统给出的出行建议、两种方案的预计时间和实时电梯状态。

## 系统考虑的因素

- 教学楼共 7 层、3 部电梯，2 楼为平层。
- 电梯每层直达运行约 2 秒；满载时不再接新乘客，但仍会在乘客目的楼层停靠下客。
- 空闲电梯会停在最后下客的楼层；有新呼叫时，由距离呼叫层最近的空闲电梯响应。
- 各楼层均有上行、下行队列，乘客会在途中上下电梯，空出的座位会继续接载同方向队列。
- 楼梯速度会随着连续爬楼产生体力衰减；下楼、上楼和携带重物分别使用不同的时间估算。
- 课间换课时，2 楼上行和 5 楼下行各有 90% 的概率出现满载。
- 当预测到 2 楼上行会满载，至少 6 名乘客会选择先下到 1 楼、留在电梯内再上行，以提高抢到电梯的机会；未预测满载时不会出现这种“倒梯”行为。

## 数据说明

本项目中的人流、电梯载客和出行时间均为基于校园生活情境建立的模拟数据，仅用于展示算法建模与交互效果，不代表真实学校的监测结果。

## 项目目标

通过将“垂直距离”转化为可计算的时间、拥挤度与体力成本，帮助学生在不同校园人流场景下做出更合适的出行选择。

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 楼层与目的地输入 | ✅ 已完成 | 支持选择 1–7 楼的出发层和目的层。 |
| 电梯 / 楼梯方案推荐 | ✅ 已完成 | 对比预计等待与乘坐时间、楼梯时间后给出建议。 |
| 楼梯体力衰减 | ✅ 已完成 | 连续上楼会逐层变慢；下楼和携带重物使用不同参数。 |
| 三部电梯实时模拟 | ✅ 已完成 | 显示电梯位置、方向、载客量与运行状态。 |
| 排队与上下客 | ✅ 已完成 | 各层分上行、下行队列；下客后才会释放空位给同方向乘客。 |
| 满载处理 | ✅ 已完成 | 满载电梯不再接客，但会在乘客目标楼层继续下客。 |
| 最近空闲电梯响应 | ✅ 已完成 | 空闲电梯停在最后下客层，并优先响应距离最近的呼叫。 |
| 课间换课人流 | ✅ 已完成 | 2 楼上行、5 楼下行按 90% 概率模拟满载情境。 |
| 倒梯抢梯行为 | ✅ 已完成 | 仅预测 2 楼上行满载时触发，且至少安排 6 人先到 1 楼再上行。 |
| 真实传感器数据接入 | ⏳ 待扩展 | 可在后续接入电梯状态、客流计数或用户反馈数据。 |
